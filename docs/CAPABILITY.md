# CAPABILITY —— FULLY_CONNECTED（int8）的能力边界图

采集：2026-11-12 · ncc-tflite 7.3.15 / `--arch=mdla5.0 --disallow-bridge` · 板 Titan 1（MT6897/MT8792）。
方法：逐形状生成 TFLite → 编译 → 记录**失败阶段**（`tools/scan_shapes.sh`，原始表 `docs/CAPABILITY.tsv`）。
**网格规模 ≠ 通过数量**：下表是"扫过的形状"，不是"支持的全部形状"。

## 1. 规则（由实测数据归纳，附适用范围）

| 维度 | 观测 | 结论（附边界） |
|---|---|---|
| K | 8/24/40/56/72 编译 **失败**（`Bridging is disallowed but gap is detected`）；16/32/48/64/80/112/128/192/256/384/512 **通过** | **K 必须是 16 的倍数**。非 16 倍数不是"运行错"，而是编译器直接判失败 |
| N | 8/16/24/32/48/64/96/128/192/256/384/512 **全部通过** | N 无 16 倍数约束（8 也可） |
| M | 1/2/7/8/31/32/127/128 **全部通过** | M 无对齐约束（7/31/127 这类尾块可编） |

> N=8 与 M=7/31/127 能**编译**，并且抽样在板上**跑通且数值正确**（见 §3）。
> 这不等于任意 M/N 组合都成立——组合空间没有全扫。

## 4. 失败分类

| 失败阶段 | 现象 | 含义 |
|---|---|---|
| **编译期** | `Bridging is disallowed but gap is detected between Input and MDLA_5_0` | 该形状需要 CPU 桥接（不是 NPU 能力边界，而是"我们策略不接受桥接"） |
| **运行期** | `There is a runtime error during inference` | 编译通过但执行被拒（E-105B 里把 `num_subcmds` 改成 0 就属于这类） |
| **数值** | `max_abs_diff > tol` | 只有 requant 边界的 ±1（见 E-003） |

## 5. 未覆盖（必须明说）

- 只扫了 **M×K×N 的单独轴**，没有扫组合（例如 M=128 且 K=8）；
- 只测 **int8**；fp16 只测了 2 个形状；fp32 不可直连（E-004）；
- 只测 **FULLY_CONNECTED**，其它算子见 W5；
- K 的上界未触及（512 通过，未测更大）；
- 未测非 4 维输入、batch>1 的 4D 形态。

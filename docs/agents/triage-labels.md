# Triage 标签

各技能用五个固定的 triage 角色来谈论状态。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库的标签 | 含义 |
| -------------------------- | ------------ | ---- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`       | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`  | 规格齐全，可以交给 AFK agent |
| `ready-for-human`          | `ready-for-human`  | 需要人来实现 |
| `wontfix`                  | `wontfix`          | 不予处理 |

技能提到某个角色时（例如"打上 AFK-ready 的 triage 标签"），就取上表右列对应的标签字符串。

要换成本仓库已有的其它标签名，改右列即可。

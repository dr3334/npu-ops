# Round-up 2026-11-12 / 13 —— 从"能给 MNPU 编译算子"到"用自己的运行时算 attention"

这一轮把 npu-ops 从"单算子能编能跑"推进到三件此前没有的东西：
**一个完整的 decoder block 能整块下沉**、**一个不依赖厂商 runtime 的自有提交器能算出一条 attention**、
以及**一份把驱动映射语义写清楚的文档**。

## 1. 算子覆盖面（厂商编译路径，`tools/run_all.sh` 回归）

`PASS=136 / XFAIL=26 / FAIL=0`，前后 `healthcheck` 均通过。

- 矩阵乘：FULLY_CONNECTED（int8 静态/动态权重、fp16），最大测到 **8192×8192（64 MB 权重）**
- 逐元素：ADD / MUL / SUB / MAXIMUM / MINIMUM（int8，逐位）
- 形状：RESHAPE / TRANSPOSE / CONCAT / SPLIT / PAD（逐位）
- 激活/归约：RELU / LOGISTIC / TANH / **SOFTMAX** / MEAN / SUM
- 卷积/池化：CONV_2D / DEPTHWISE_CONV_2D / MAX_POOL / AVG_POOL
- 归一化：**RSQRT 是原生层**，RMSNorm 链（MUL→MEAN→ADD→RSQRT→MUL→MUL）同一个执行步
- 位置编码：RoPE（Qwen2 split-half），**sin/cos 表可作为运行时输入**
- 注意力矩阵乘：BATCH_MATMUL，**两个操作数都是运行时张量**

## 2. 整块 transformer（厂商路径）

| 变体 | 层数 | 结果 |
|---|---|---|
| `block_qwen25_1l_fp16`（无 Norm/RoPE） | 16 | 单 MDLA 步，max_abs 9.77e-04 |
| `block_qwen25_1l_norm_fp16`（+RMSNorm） | 24 | 同上 |
| `block_qwen25_1l_full_fp16`（+RoPE，T=8） | **42** | 单 MDLA 步，`.dla` 91.8 KB，rmse 1.86e-04 |
| `block_qwen25_1l_full_t128_fp16`（T=128 prefill） | 42 | rmse 1.90e-04 |

| `block_qwen25_multhead_h2_fp16`（**2 头**，RESHAPE+BMM 路径） | 31 | 单 MDLA 步，板端 **PASS**（1 ULP） |
| `block_qwen25_multhead_h14_fp16`（**14 头 / H=896 / HD=64**，真实形状） | 33 | 单 MDLA 步，`.dla` 7.06 MB，板端 **PASS** |

> 订正（ticket 01）：多 head 变体此前记为"在 importer 失败 / WIP"——**那是构造器 bug**（权重张量按 FC
> 目标宽度声明，`heads=14` 时声明 896×896 而数组只有 64×896 ⇒ ncc **加载期**退出），不是 importer 限制。
> 修好后两个多头整块都编译+板端通过；顺带发现"直接 reshape 成 `[heads,T,HD]` 能编但数值错"。
> 详见 `docs/OP-block.md §10`。

## 3. 自有提交器（不经过 `libneuron` / `neuronrt`）

`probe/npu_binop.c` + `probe/mkasset*.sh`：自己完成 握手 → ALLOC/mmap/MAP → 写内容 →
命令流地址重定位 → 组装 `mdw_cmd_in`/`subcmd_info`/`cmdbuf` → `CMD RUN` → 等待+同步 → 读回。

| 能力 | 结果 |
|---|---|
| 逐元素 5 个 + RELU | 各 `0/64` |
| FC（动态权重 64×64 / 512×512 / 1024×1024） | `1/64`（requant 边界）/ `0/512` / `0/1024`，均连跑 3 次一致 |
| **完整 attention（T=16, int8，51 次提交）** | `s=0/256  p=0/256  o=0/1024` |

链路里发现的两处必须自己做的事：softmax 的 **LUT 缓冲**要随资产重放；softmax→PV 之间要做
**量化域转换**（`(1/256, zp=-128)` → `(1/127, zp=0)`）。

## 5. 已知未解（不粉饰）

1. `.dla` 不是字节可复现的（同 tflite 三次编译 sha256 不同），回归只比数值；
2. 常量权重 FC：提交链路通、数值不稳（11 次里 3 次正确），疑在 8 KiB 常量区的映射语义；
3. ~~多 head 整块：importer 报 `Fail to process the given model`~~ → **已定为构造器 bug 并修复**
   （`tools/build_block2.py`，见 `docs/OP-block.md §10`）；剩下的是 **H=896 整块的容差口径**
   （spec 的 2e-2 上限 vs `|out|` 到 8.46）需要 spec/Lead 拍板；
4. 大/小地址段（`0x25xxxxxx` vs `0xca/0xcbxxxxxx`）的切换阈值未做阶梯实验。

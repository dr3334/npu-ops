# 01: 常量权重 FC 的 IoVA 契约

**Type:** research
**Status:** open
**Blocked by:** None

## Question

自建提交器上，常量权重 FC 只在常量缓冲恰好落在「抓取时那个 IoVA」时才对（11 次里 3 次正确）。三条候选假设（docs/ISSUE-const-fc.md §10.2/§10.3）：① 8 KiB 常量区在驱动/固件层的映射语义；② flush / cache 维护差异；③ 三块缓冲的角色互换。

**要回答**：权重能不能「常量编进资产、在任意 IoVA 上重放」？如果不能，替代是不是「权重作为常驻 dma-buf 的运行时输入」（动态权重路径，已验证 0/512、0/1024）？

**判据**：同一命令流、同一输入，在不同 IOVA 分配下输出与厂商路径逐字节相同，且至少 5 次不同分配都成立。

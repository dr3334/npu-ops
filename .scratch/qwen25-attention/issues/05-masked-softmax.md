# 05: 掩码 + 原生 SoftMax

**What to build:** 带因果掩码的 softmax 第一次在设备上成立。关键约束：推理路径里**没有 EXP 算子**，所以"手写 exp 链"这条路不存在，掩码只能靠"加法进图 + 原生 SoftMax"。掩码值不能被写成无穷小，也不能靠一个过大的常数赌博——要在 fp16 下确定性地把被掩码位置压到 0。

**Blocked by:** 02

**Status:** done

- [ ] 掩码在 scale **之后**相加（顺序影响量级，必须记清楚）
- [ ] 掩码值取受控有限负值：不使用 −inf，也不使用 −10000
- [ ] 专项判据一：被掩码位置的 softmax 输出**为 0**
- [ ] 专项判据二：非掩码位置与无掩码版本的输出**一致**
- [ ] 整张量与 golden 的偏差在阈值内，阈值由本算子的噪声底实测决定
- [ ] 记录"无 EXP 算子"这一约束，以及它是怎么把方案收敛到唯一形态的
